## 演示和验收

在仓库根目录用 Python 3.9 或更高版本执行：

```text
python -m unittest discover -s tests -v
python examples/demo.py
python -m src.my_tool.main
````

浏览器打开 http://127.0.0.1:8000，按顺序演示：查看四间实验室 → 用“Python”和 20 人测试推荐 → 提交预约 → 对同一场地和时段重复预约并观察冲突提示 → 审批原申请 → 登记“电源插座冒烟”并演示人工关闭。

目标流程图展示后续 AI 辅助环节；本次 MVP 用规则推荐和关键词提示模拟这些环节，未调用大模型。审批和安全判断由人工负责。报价为课程模拟估算，MVP 无需云环境即可验收。
