# LabPilot：实验室数智化管理系统（MVP）

**作者：f25011219 陈科宇｜课程项目｜2026-11-04**

围绕高校实验室资源预约、设备/场地台账和安全巡检的最小可用 Web 演示。包含实验室浏览、条件推荐、预约提交、时段冲突检测、预约审批、安全隐患登记、关键词规则辅助风险提示及关闭处理。

> **重要说明**：当前所谓“智能辅助”仅为透明的规则推荐/关键词提示，**没有调用大模型、没有训练 AI，也不是经过校方认证的安全风险分级算法**。审批操作未实现身份认证，仅适用于本地演示，禁止开放在公网作为正式业务系统。

## 零依赖启动

需要 Python 3.9 或更新版本。在仓库根目录执行：

```bash
python -m src.my_tool.main
```

浏览器访问 http://127.0.0.1:8000 。首次运行自动生成 `data/lab.db` 和四间演示实验室；删除该 DB 后可重置。

## 单元测试

```bash
python -m unittest discover -s tests -v
```

## 项目结构

- `src/my_tool/main.py`：HTTP API 与 SQLite 数据层
- `src/my_tool/core/rules.py`：可解释规则推荐与隐患关键词提示
- `src/my_tool/web.html`：响应式前端
- `docs/`：业务挖掘、行业分析、双流程图、报价单、设计方案、API 说明
- `tests/`：核心规则与功能测试
- `examples/demo.py`：命令行示例

## 演示路径

打开首页 → 实验室与推荐 → 预约申请 → 审批列表 → 安全巡检（输入“电源插座冒烟”）→ 标记关闭。

## 已知局限

无身份认证/RBAC、无真实大模型、无多用户并发锁定事务、无消息推送、无危险源专业风险模型。用于教学验证，不可替代安全员决策或正式生产系统。
